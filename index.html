如果你在做課程專題，先從「系統網頁包」開始。

先選任務，再看需要哪些 skills。

每一包只放能串成完整流程的幾個 skill，點一下，下面的清單就只留這一包。6 包加起來 33 個位置，其中Reels 腳本、Reels 成片、繁中去 AI 味、逼問到想清楚會在不只一包出現，所以實際是 28 個不重複的 skill；收錄的 104 個裡，其他 76 個在下方完整清單。

或依功能分類看全部。

收錄的 104 個分成 11 類，點一類就在下面只顯示那一類。分類是全部，套餐是挑過的精選，所以數字不一樣：「社群行銷」共 18 個，社群經營包只用了其中 6 個，另外 1 個來自別的分類；「簡報」共 2 個，簡報企劃包只用了其中 2 個，另外 3 個來自別的分類。

沒有符合的 skill

換個關鍵字，或放寬上面的條件。

星等衡量的是「今天能不能用」。

評分角度是在職專班同學的日常：做系統和網頁專題、寫報告、做簡報。看使用頻率、設定成本和成果明不明確。

這不是品質認證；如果你的課程或工具不同，低星的 skill 仍可能很有用。Claude 內建的 skill（Word、Excel、PPT、PDF 等）不需要安裝，所以不列在這份清單裡。

看來源，三種裝法。

最快的方法是按卡片上的「直接安裝」：會開新的 Claude 對話並帶入安裝指令，指令也同時複製好了，沒帶入就貼上送出。

GitHub

上傳 ZIP

  1. 按卡片上的「查看來源」，下載 ZIP。
  2. 解壓縮，把放著 SKILL.md 的資料夾單獨壓成 ZIP，資料夾名稱要跟 skill 名稱一樣；scripts、data 等附屬檔案要一起放進去。
  3. 到 Customize → Skills，按「+」→ Create skill → Upload a skill，上傳 ZIP。

上傳的 skill 只有你自己看得到。官方說明：Using Skills in Claude

自製 skill

複製指令，貼給 Claude

本站自己寫的 skill（目前是 Reels 成片），原始檔放在本站的 GitHub repo。按卡片上的「複製安裝指令」，整份 SKILL.md 會一起複製；在新開的 Claude 對話貼上送出，照提示存成 skill。也可以按「查看來源」到 GitHub 看原始檔。

需要先在設定裡開啟程式碼執行與檔案建立。

Plugin

一次裝好一整包

在 Claude 對話裡說「幫我安裝 Superpowers plugin」，或到 claude.com/marketplace 搜尋名稱。

三個 plugin 整包共 56 個 skill，本站挑出 45 個：Skills For Real Engineers（Matt Pocock） 整包 39 個、收錄 31 個；Superpowers 整包 15 個、收錄 12 個；ffmpeg-llm 2 個全收。沒收的多半是重複，或只適合工程師。裝 plugin 會整包裝進來。前兩個主要給寫程式的人，能不能裝要看你的方案和 App 版本。

想重新開始，還是保留目前的篩選？

「回首頁」會清掉篩選和套餐，從推薦起點重選；「回到上方」只捲回最上面，篩選都還在。
